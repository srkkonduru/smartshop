# Smartshop

A lightweight, offline-first shopping list & inventory app.

**Live demo:** (after you enable GitHub Pages)  
`https://YOUR_USERNAME.github.io/REPO_NAME/`

## Features

- Shopping list with priority, swipe actions, and smart suggestions
- Inventory with low-stock & expiry tracking
- Future / planned purchases
- Spending analytics & monthly budget alerts
- Receipt & shopping-list upload (OCR)
- Barcode scanning
- Local backup / restore (JSON + CSV)
- Fully client-side — data stays in your browser

## Deploy to GitHub Pages

1. Create a new repository on GitHub (public recommended for free Pages).
2. Push this folder:

```bash
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git branch -M main
git push -u origin main
```

3. In the repo → **Settings → Pages**:
   - Source: **Deploy from a branch**
   - Branch: `main` / `/ (root)`
   - Save

Your app will be live at:  
`https://YOUR_USERNAME.github.io/YOUR_REPO/`

## Local use

Just open `index.html` in any modern browser. No build step required.
